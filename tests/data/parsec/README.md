# PARSEC test fixtures

## `parsec_cmd_v1p2S_fixture.dat`

A format-equivalent synthetic CMD isochrone table in the OLDER documented
layout — parser test data for the pre-version-echo reader, NOT science
data.

- Why synthetic: real CMD 3.9 outputs use a different, per-row-keyed
  column vocabulary (real captures live under `cmd_form/`); the documented
  layout is kept for older CMD outputs, and no verified real sample of it
  is at hand.
- Header block: modeled on a real CMD server response for a
  PARSEC v1.2S + COLIBRI S_37 + S_35 + PR16, UBVRIJHK, no-extinction
  request, minus the `File generated by CMD` version echo — files in this
  layout carry none, and the reader dispatches on that echo.
- Column layout: the documented format — Girardi isochrone readme
  "TABLES OF ISOCHRONES" section
  (`pleiadi.oapd.inaf.it/isoc_photsys.02/readme.txt`) plus the CMD
  updates stated on the official help page (FLUM replaced by `int_IMF`;
  `C/O`, `M_hec`, `logMdot`, `label` added). Columns: `log(age/yr) M_ini
  M_act logL/Lo logTe logG label U B V R I J H K int_IMF C/O M_hec logMdot`
  (19 columns).
- Data rows: hand-computed with `make_parsec_fixture.py` (same directory) —
  plausible monotone mass-luminosity-temperature relations, two isochrones
  (log10(age/yr) = 9.0 and 9.5, 40 rows each) at Z = 0.0152 with
  Y = 0.2485 + 1.78 Z, per-isochrone header lines carrying Z/Y/X/age in the
  documented "HEADER LINE" style.

Real captures from the CMD 3.9 form plus one derived synthetic multi-block
